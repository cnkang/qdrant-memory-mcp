# Qdrant Memory MCP 0.2.3

[English](0.2.3.md) | [简体中文](0.2.3.zh-CN.md)

本版本对齐源码验证，并为包含 Skill 0.3.2 的 Connector 0.2.1 做好准备。
该 Skill 包含安装器隔离和私有 ACL 检查。

- Owner 生命周期 CI 使用已审核的不可变 Runtime 源码提交。
- Python 分发仍选择 Runtime 0.4.0。受管安装仍使用 launcher `0.1.0-rc.3`。
  源码 CI 不会升级这两个产物。
- Pi 使用隔离的 Python 解释器执行 Owner 命令。CI 源码回退校验仓库和版本，
  并在 pull request 中保持禁用。
- 当前 Python MCP 示例与 DSH uvx 配置选择 MCP 0.2.3。
- 历史 Cloud 和桌面验证结果保留其原始测试提交。

安装前请在 [PyPI](https://pypi.org/project/qdrant-memory-mcp/0.2.3/) 确认包已提供。
Connector 资产在 [GitHub 发布页面](https://github.com/cnkang/qdrant-memory-mcp/releases)
单独发布。这些元数据变更不会迁移 profile、模型、集合或 Runtime。

验证和发布步骤见[发布检查清单](../publishing.zh-CN.md)。四个 scoped 工具和私有默认
行为保持不变。普通 stdio MCP 不会自动捕获对话。独立的自动生命周期与远程访问边界见
[Owner 支持记录](../universal-owner-status.zh-CN.md)。
