# MCP distribution 0.3.3

This release aligns the metadata-only MCP package with the published Runtime
0.6.2. MCP 0.3.2 required Runtime 0.6.1 and therefore could not be resolved
alongside the current Runtime pin.

The four MCP tools, schemas, Qdrant schema and persisted memory format are
unchanged. The package remains a thin adapter over the shared Runtime.

Release workflow, public PyPI and Registry evidence will be recorded here after
the protected exact-SHA release completes.
