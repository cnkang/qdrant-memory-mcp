# Qdrant Memory MCP 0.1.3

[English](0.1.3.md) | [简体中文](0.1.3.zh-CN.md)

本兼容补丁在新的 GitHub Release 提供 WorkBuddy MCP + Skill Connector ZIP
及校验文件。Connector 0.1.0 精确启动 MCP 0.1.3，并包含来自 `cnkang/skills`
不可变提交 `405d5664a6b682adefbaef7513653607a420e757` 的 Skill 0.2.5。
该 Skill 及其打包器与 `skills-20261015.1` Snapshot 中的内容一致。

分发包保持仅含元数据，固定 Runtime 0.2.2。MCP Python SDK 1.x/2.x、
入口、四个作用域工具、stdio 参数、Profile 格式与存储行为均不变。
现有 Profile 无需迁移；保留 Collection、作用域和 Embedding 配置，保持单写者。

```bash
uvx --from qdrant-memory-mcp==0.1.3 qdrant-memory-mcp --home /path/to/profile mcp
```

运行前确认该版本已在 PyPI 公开。wheel/sdist 安装与协议验收覆盖两个 SDK 主版本，
以及 Linux、macOS、Windows 和 Python 3.11/3.14。WorkBuddy ZIP 包含双语元数据、
不可变来源记录及 SHA-256 校验文件。

WorkBuddy 4.24.0+ 需要 PATH 中的 uvx、Python 3.11+、已配置并初始化的
Memory Profile 和就绪的 Embedding 服务，连接前请预热依赖。本 Connector 面向
预配置环境，尚未认证托管式一键安装、ZIP 导入或市场审核。独立 Skill ZIP
仅提供使用指导，不含 Runtime。详见 [WorkBuddy 配置与限制](../../integrations/workbuddy/README.md)。

已有版本和附件保持不变。本 Connector 请使用 0.1.3 Release 的资产；
0.1.2 不含 Connector ZIP。
