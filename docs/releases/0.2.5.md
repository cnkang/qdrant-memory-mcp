# MCP distribution 0.2.5

MCP distribution 0.2.5 selects Runtime 0.5.1, a patch that fixes the protected
Owner recovery path. The tool schemas, the transport and the authorization rules
are unchanged.

## Changes

- Select the published Runtime 0.5.1 wheel and the `v0.5.1` tag revision.
- Ship launcher 0.1.0-rc.5 with the Runtime 0.5.1 payload and dependency lock.
- Select DSH bundle 0.1.4 and Skill 0.3.4.
- Update the integration guides, the version tables and the CI pin.

## Install

Check that Runtime 0.5.1 is available on PyPI before installation.

```sh
uvx --from 'qdrant-memory-mcp==0.2.5' qdrant-memory-mcp --help
```

For the shared Owner deployment, install the Runtime in its own environment:

```sh
python -m venv ~/.local/share/qdrant-owner-env
~/.local/share/qdrant-owner-env/bin/pip install \
  'hermes-plugin-qdrant-memory[local,mcp,remote]==0.5.1'
```

## Upgrade

Replace the distribution pin and restart the MCP client. The Runtime upgrade
keeps the collection identity and the ledger. No migration step is required.

## Verification and limits

- The repository suite runs against the pinned Runtime.
- The two-device acceptance report records the Runtime behaviour on 0.5.0 and the
  recovery defects that 0.5.1 fixes.
- Managed installs use the launcher payload. A host that already provisioned
  Runtime 0.5.0 keeps that environment until the launcher reprovisions it.
