# MCP distribution 0.3.1

MCP distribution 0.3.1 keeps Runtime 0.6.0 and its existing four stdio tools.
This release refreshes the launcher 0.1.0-rc.8 integrity pin to match the
public npm artifact, so WorkBuddy and DSH release checks verify the same bytes
that users install. The MCP protocol, tool schemas, profiles and stored data do
not change.

WorkBuddy connector 0.2.5 and DSH bundle 0.1.6 select the verified launcher.
Their downloadable assets and npm publication have separate build, acceptance
and publication steps. Verify PyPI, the MCP Registry and npm independently
before using an exact-version install command.

Runtime 0.6.0, Skill 0.4.0 and the Codex plugin candidate remain independently
versioned. Codex Marketplace submission remains paused. The FastEmbed
0.9.0-to-0.9.1 pipeline migration guidance from [0.3.0](0.3.0.md) still applies.
