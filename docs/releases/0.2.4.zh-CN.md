# Qdrant Memory MCP 0.2.4

[English](0.2.4.md) | [简体中文](0.2.4.zh-CN.md)

本次发行选择已公开发布的 Runtime 0.5.0 包。准备阶段源码和 Owner CI
固定到同一个不可变发行提交。分发包仍只包含元数据，全部记忆操作交由 Runtime。

- WorkBuddy Connector 0.2.2 与 DSH bundle 0.1.3 选择 launcher 0.1.0-rc.4。
- launcher 安装 Runtime 0.5.0、Pillow 13.0.0 和已验证的
  FastEmbed 0.9.0+qm.pillow13 兼容 wheel，推理文件保持不变。
- 兼容构建器复用 Runtime 的既有实现。执行与安装前分别验证源码和输出，
  依赖检查仍为必需。
- 程序安装目录随依赖哈希变化，已有 profile 和模型缓存继续可用。
  不迁移集合或模型。
- 私有默认值和四个固定作用域 stdio 工具保持不变。自动捕获仍需单独验证的
  宿主生命周期适配器。

安装前请在 [PyPI](https://pypi.org/project/qdrant-memory-mcp/0.2.4/) 和
[GitHub 发行资产](https://github.com/cnkang/qdrant-memory-mcp/releases)
确认可用性。历史 Cloud 和桌面证据保留原测试版本；更新 pin 不代表重跑这些测试。
