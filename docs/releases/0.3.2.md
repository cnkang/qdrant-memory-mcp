# MCP distribution 0.3.2 release candidate

This candidate is not published yet. Until PyPI lists 0.3.2, use the published
`qdrant-memory-mcp==0.3.1` installation instructions.

MCP distribution 0.3.2 pins the published Runtime 0.6.1. This gives the
separately installed, opt-in Codex lifecycle preview access to the Runtime
`remote-event` candidate interface without sending raw turn transcripts to the
Owner. The public portable Codex plugin and its Runtime package remain
independently versioned and need their own release update.

The four stdio MCP tool schemas, Qdrant schema and persisted memory format do
not change. Owner candidate submission still requires an explicit operator
confirmation and an authorized Runtime grant. Retries use the same immutable
Owner event; failed or quarantined events stay pending until a Runtime operator
recovers them.

This release does not establish Codex Desktop GUI hook acceptance or a real
authenticated Owner endpoint test. The lifecycle preview remains experimental
and is not eligible for the public plugin directory.
