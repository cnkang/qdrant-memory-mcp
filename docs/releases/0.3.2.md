MCP distribution 0.3.2 pins the published Runtime 0.6.1 API. This gives the
separately installed, opt-in Codex lifecycle preview access to the Runtime
`remote-event` candidate interface without sending raw turn transcripts to the
Owner. The public portable Codex plugin and its Runtime package remain
independently versioned.

The four stdio MCP tool schemas, Qdrant schema and persisted memory format do
not change. Owner candidate submission still requires explicit operator
confirmation and an authorized Runtime grant. Retries use the same immutable
Owner event; failed or quarantined events stay pending until a Runtime operator
recovers them.

The release workflow tested the wheel and sdist with MCP SDK 1.x and 2.x. Each
of the four runs reported 635 passed and 1 skipped. The skipped test parses
documented PowerShell examples; PowerShell is unavailable on the Ubuntu
release runner, so this skip is not counted as a pass. The exact-SHA release
gate and published PyPI/Registry acceptance passed.

The GitHub Release includes the WorkBuddy connector 0.2.5 ZIP built for MCP
0.3.2, its checksum, a CycloneDX 1.6 SBOM and a license metadata aggregation.
The lifecycle preview remains experimental: this release does not establish
Codex Desktop GUI hook acceptance or a real authenticated Owner endpoint test,
and is not eligible for the public plugin directory.
