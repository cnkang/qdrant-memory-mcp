# Qdrant Memory MCP 0.1.4

Python MCP 发行包现在精确依赖已公开发布的 Runtime 0.3.0。现有 CLI、四个
MCP 工具及 Python/uvx 安装方式保持兼容。Hermes 原生插件独立管理，现有用户
无需因其他宿主适配而升级。

Runtime 0.3.0 提供可显式选择的本地 CPU Embedding。可选的托管启动器安装经过
校验的公开 wheel 和完整锁定的依赖，不再构建 Runtime 源码，也不依赖系统
Python、uv/uvx、Ollama 或 Qdrant Server。

启动器升级时保留已有 Profile 的模型缓存配置；安装快照支持安全恢复，并拒绝
并发准备。MCP Bridge 会安全拒绝非法后端响应，不排队或自动重放记忆写入。

启动器与各宿主包独立版本管理，目前作为发行候选进行验收。跨平台自动化测试与
真实桌面 Connector 安装分别验证；MCP 连接成功不代表后端准备完成。

```sh
uvx --from qdrant-memory-mcp==0.1.4 qdrant-memory-mcp mcp
```

请先按[快速开始](../quickstart.zh-CN.md)准备 Profile 和 Embedding Provider。
升级前备份数据，保留相同的 Profile、Scope 和 Embedding Pipeline。程序不执行
自动数据迁移。
