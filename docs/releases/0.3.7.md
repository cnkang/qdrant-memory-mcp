# MCP distribution 0.3.7

MCP 0.3.7 is a metadata-only stdio distribution pinned to the public Qdrant
Memory Runtime 0.7.3 release. It retains the same four explicitly scoped tools:

- `qdrant_memory_search`
- `qdrant_memory_add`
- `qdrant_memory_update`
- `qdrant_memory_delete`

This release does not change the MCP tool schemas, scope behavior, or Runtime
data schema. It does not add automatic conversation capture or maintenance
tools.

Until exact version 0.3.7 is available on both [PyPI](https://pypi.org/project/qdrant-memory-mcp/0.3.7/)
and the [MCP Registry](https://registry.modelcontextprotocol.io/v0.1/servers/io.github.cnkang%2Fqdrant-memory/versions/0.3.7),
continue using the published 0.3.6 package.

## Install

After confirming 0.3.7 is available on both services above, install it with:

```sh
uvx --from qdrant-memory-mcp==0.3.7 qdrant-memory-mcp --home /path/to/profile mcp
```

Until then, use the previous release:

```sh
uvx --from qdrant-memory-mcp==0.3.6 qdrant-memory-mcp --home /path/to/profile mcp
```

The distribution resolves `hermes-plugin-qdrant-memory[mcp]==0.7.3` from PyPI.
It does not install Hermes. The managed launcher, WorkBuddy connector and DSH
Bundle have separate release versions and pins.

The release workflow validates the built wheel and source distribution against
the public Runtime, checks MCP Python SDK 1.x and 2.x compatibility, and runs
the stdio protocol acceptance before publishing the Registry entry.
