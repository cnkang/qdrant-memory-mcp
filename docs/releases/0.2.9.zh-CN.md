# MCP 发行包 0.2.9

MCP 发行包 0.2.9 选择已公开的 Runtime 0.5.5 兼容性版本，并记录其不可变源码修订。
该 Runtime 版本更新 FastEmbed 以兼容 Pillow，同时保持现有行为。

## 变更

- 固定依赖 `hermes-plugin-qdrant-memory[mcp]==0.5.5`。
- 将 MCP Registry 元数据和精确安装示例更新到 0.2.9。
- 四个 MCP 工具、schema、stdio 传输、scope 规则和已存数据均不变；无需迁移，
  也不改变 collection schema。
- 启动器和 DSH Bundle 包产物不变，本次无需发布 npm 包。

## 升级

更新精确版本固定值并重启 MCP 客户端，使其创建新进程。现有 profile、模型缓存和
记忆数据会原样复用。
