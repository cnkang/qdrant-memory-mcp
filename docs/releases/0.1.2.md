# Qdrant Memory MCP 0.1.2

[English](0.1.2.md) | [简体中文](0.1.2.zh-CN.md)

This patch pins Runtime 0.2.2, adding MCP Python SDK 1.x and 2.x support.
The distribution remains metadata-only: it delegates to the shared Runtime
and keeps the same executable, four scoped tools and local stdio arguments.

```bash
uvx --from qdrant-memory-mcp==0.1.2 qdrant-memory-mcp --home /path/to/profile mcp
```

Configure and initialize the profile before starting MCP. Existing profiles
require no data migration; retain the collection, scope and embedding pipeline.
One writer per destination remains required.

Wheel and sdist acceptance exercise both SDK majors, including initialization,
tool discovery, scoped CRUD, input refusal and restart recovery. CI covers
Linux, macOS and Windows with Python 3.11 and 3.14. Protocol acceptance does
not certify every live agent application.
