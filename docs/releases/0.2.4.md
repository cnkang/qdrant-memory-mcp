# Qdrant Memory MCP 0.2.4

[English](0.2.4.md) | [简体中文](0.2.4.zh-CN.md)

This release selects the public Runtime 0.5.0 package. Its preparation source
and Owner CI use the same immutable release revision. The distribution remains
metadata-only and delegates all memory operations to the Runtime.

- WorkBuddy Connector 0.2.2 and DSH bundle 0.1.3 select launcher 0.1.0-rc.4.
- The launcher installs Runtime 0.5.0, Pillow 13.0.0 and the verified
  FastEmbed 0.9.0+qm.pillow13 compatibility wheel. Inference files stay unchanged.
- The compatibility builder is the existing Runtime implementation. Its source
  and output are verified before execution and installation. Dependency checks
  remain required.
- Program installation directories change with dependency hashes. Existing
  profiles and model caches remain available. No collection or model is migrated.
- Private defaults and the four scoped stdio tools remain unchanged. Automatic
  capture still requires a separately verified host lifecycle adapter.

Check [PyPI](https://pypi.org/project/qdrant-memory-mcp/0.2.4/) and the
[GitHub release assets](https://github.com/cnkang/qdrant-memory-mcp/releases)
for availability before installation. Historical Cloud and desktop evidence
keeps its original tested versions; a pin update does not repeat those tests.
