# MCP 分发 0.3.5

MCP 0.3.5 是仅含元数据的 stdio 分发，固定依赖公开的 Runtime 0.7.1，并保持
四个作用域工具不变：

- `qdrant_memory_search`
- `qdrant_memory_add`
- `qdrant_memory_update`
- `qdrant_memory_delete`

Runtime 0.7.1 保留中断升级已记录的恢复点，并在 Shared Owner 仍持有已落盘、但
关联事件尚未到达终态的生命周期回执时，阻止 upgrade plan、apply 或 resume。

## 安装

```sh
uvx --from qdrant-memory-mcp==0.3.5 qdrant-memory-mcp --home /path/to/profile mcp
```

该分发从 PyPI 解析 `hermes-plugin-qdrant-memory[mcp]==0.7.1`，不安装 Hermes，
也不通过 MCP 暴露任何 Runtime 维护命令。托管启动器、WorkBuddy 连接器与 DSH
bundle 各自选择 Runtime 版本，分别发布。
