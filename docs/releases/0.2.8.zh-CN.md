# MCP 发行包 0.2.8

MCP 发行包 0.2.8 选择已发布的 Runtime 0.5.4。Runtime 0.5.4 是可维护性版本：
它保持 0.5.3 的行为，把长函数拆成具名辅助函数。本包仍只分发元数据，
实现继续委托给 Runtime。

## 变更

- 固定 `hermes-plugin-qdrant-memory[mcp]==0.5.4`。
- 更新 MCP Registry 元数据与精确安装示例到 0.2.8。
- CI 依赖一律从哈希锁文件安装，并在仓库质量工作流中加入 SonarCloud 扫描，
  覆盖默认分支与拉取请求。
- Pi 宿主验收环境升级到 `minimatch` 11.0.1，WorkBuddy 通道升级到
  `uv` 0.13.6，均已越过对应公告。
- 四个 MCP 工具、其 schema、stdio 传输、scope 规则与已存数据均不变。
  无需迁移，也不改变 collection schema。
- 托管 WorkBuddy/DSH 启动器的载荷仍停留在 Runtime 0.5.2。该载荷使用独立的
  MCP 入口，不会实例化 Hermes 原生的 MemoryProvider，因此本版本不需要
  发布 npm 包。

## 升级

更新精确版本固定值并重启 MCP 客户端，使其创建新进程。现有 profile、
模型缓存与记忆数据会原样复用。
