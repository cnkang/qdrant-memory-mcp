# Qdrant Memory MCP 0.2.3

[English](0.2.3.md) | [简体中文](0.2.3.zh-CN.md)

This release aligns source validation and includes Connector 0.2.1 with Skill
0.3.2. The Skill includes installer isolation and private ACL checks.

- Owner lifecycle CI uses a reviewed immutable Runtime source revision.
- The Python distribution still selects Runtime 0.4.0. Managed installations
  still use launcher `0.1.0-rc.3`. Source CI does not upgrade either artifact.
- Pi runs the Owner command with an isolated Python interpreter. The CI source
  fallback checks its repository and version and stays disabled for pull requests.
- Active Python MCP examples and the DSH uvx overlay select MCP 0.2.3.
- Historical Cloud and desktop results keep their original tested revisions.

Check [PyPI](https://pypi.org/project/qdrant-memory-mcp/0.2.3/) for package
availability before installation. Connector assets are published separately on
the [GitHub release page](https://github.com/cnkang/qdrant-memory-mcp/releases).
No profile, model, collection or Runtime is migrated by these metadata changes.

See the [release checklist](../publishing.md) for verification and publication.
The four scoped tools and private defaults remain unchanged. Ordinary stdio MCP
does not automatically capture conversations. See the [Owner support record](../universal-owner-status.md)
for the separate automatic lifecycle and remote access boundaries.
