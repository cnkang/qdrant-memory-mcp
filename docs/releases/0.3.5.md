# MCP distribution 0.3.5

MCP 0.3.5 is a metadata-only stdio distribution. It pins the public Runtime
0.7.1 release and keeps the same four scoped tools:

- `qdrant_memory_search`
- `qdrant_memory_add`
- `qdrant_memory_update`
- `qdrant_memory_delete`

Runtime 0.7.1 preserves the recorded recovery point of an interrupted upgrade.
It also blocks an upgrade plan, apply or resume while the Shared Owner has an
admitted lifecycle receipt whose event is not terminal.

## Install

```sh
uvx --from qdrant-memory-mcp==0.3.5 qdrant-memory-mcp --home /path/to/profile mcp
```

The distribution resolves `hermes-plugin-qdrant-memory[mcp]==0.7.1` from PyPI.
It does not install Hermes and does not expose any Runtime maintenance command
through MCP. The managed launcher, WorkBuddy connector and DSH bundle select
their own Runtime versions and are released separately.
