# MCP 分发 0.3.2 发布候选

此候选版本尚未发布到 PyPI。发布前请继续使用已公开发布的
`qdrant-memory-mcp==0.3.1` 安装说明。

MCP 分发 0.3.2 固定使用已公开发布的 Runtime 0.6.1。这样，独立安装且需要显式启用的
Codex lifecycle 预览可以调用 Runtime 的 `remote-event` 候选接口，而无需向 Owner 发送原始对话。
公开 Portable Codex 插件及其 Runtime 仍独立版本管理，需要单独升级。

四个 stdio MCP 工具 schema、Qdrant schema 和已持久化的记忆格式均未改变。Owner 候选提交仍要求
操作者显式确认，并通过已授权的 Runtime grant。重试使用同一不可变 Owner event；FAILED 或
QUARANTINED 事件保持待处理状态，直到 Runtime 运维人员恢复。

本版本不代表 Codex Desktop GUI hooks 已验收，也不代表已连接真实认证 Owner endpoint。
Lifecycle 预览仍为实验功能，不符合公共插件目录提交资格。
