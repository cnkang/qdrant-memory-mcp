# Qdrant Memory MCP 0.1.2

[English](0.1.2.md) | [简体中文](0.1.2.zh-CN.md)

此补丁固定依赖 Runtime 0.2.2，新增 MCP Python SDK 1.x 和 2.x 支持。
发行包仍只包含元数据，调用共享 Runtime，保留相同的可执行命令、四个固定
作用域工具和本地 stdio 参数。

```bash
uvx --from qdrant-memory-mcp==0.1.2 qdrant-memory-mcp --home /path/to/profile mcp
```

启动 MCP 前先配置并初始化 profile。已有 profile 无需数据迁移；保留相同的
collection、作用域和 embedding pipeline。每个目标仍只允许一个写入者。

wheel 和 sdist 验收分别覆盖两种 SDK 主版本，验证初始化、工具发现、固定
作用域 CRUD、输入拒绝及重启恢复。CI 覆盖 Linux、macOS、Windows 的
Python 3.11 和 3.14。协议验收不代表所有实际 agent 应用均已通过验证。
