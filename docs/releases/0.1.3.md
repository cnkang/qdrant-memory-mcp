# Qdrant Memory MCP 0.1.3

[English](0.1.3.md) | [简体中文](0.1.3.zh-CN.md)

This compatible patch distributes WorkBuddy MCP + Skill Connector ZIP/checksum
assets with the new GitHub Release. Connector 0.1.0 launches exactly MCP 0.1.3
and includes Skill 0.2.5 from `cnkang/skills` commit
`405d5664a6b682adefbaef7513653607a420e757`. That Skill and its builder are
unchanged in snapshot `skills-20261015.1`.

The distribution remains metadata-only and pins Runtime 0.2.2. MCP Python SDK
1.x and 2.x, the console entrypoint, four scoped tools, stdio arguments, profile
format and storage behavior are unchanged. Existing profiles need no migration.
Preserve collection, scope and embedding configuration and allow one writer.

```bash
uvx --from qdrant-memory-mcp==0.1.3 qdrant-memory-mcp --home /path/to/profile mcp
```

Confirm public PyPI availability before using this exact-version command.
Wheel/sdist installation and protocol acceptance cover both SDK majors on
Linux, macOS and Windows with Python 3.11 and 3.14. WorkBuddy ZIPs include
bilingual metadata, immutable source provenance and SHA-256 checksum files.

WorkBuddy 4.24.0+ requires uvx on PATH, Python 3.11+, an operator-configured and
initialized Memory Profile, and a ready embedding service. Warm dependencies
before connecting. This is a connector for preconfigured environments.
Managed one-click installation, ZIP import and marketplace approval are not
certified. The separate Skill-only ZIP provides guidance without a Runtime.
See [WorkBuddy setup and limits](../../integrations/workbuddy/README.md).

Published versions and assets remain unchanged. Use the 0.1.3 Release assets
for this Connector. 0.1.2 has no Connector ZIP.
