# MCP distribution 0.3.6

MCP 0.3.6 is a metadata-only stdio distribution. It pins the public Runtime
0.7.2 release and keeps the same four scoped tools:

- `qdrant_memory_search`
- `qdrant_memory_add`
- `qdrant_memory_update`
- `qdrant_memory_delete`

Runtime 0.7.2 records a local Ledger write watermark in each upgrade plan.
`upgrade apply` and `upgrade resume` compare that value under the profile writer
lease and refuse an interrupted plan when this Runtime committed a write after
the plan was created. The refusal keeps the old plan and its recovery point, so
an operator can review the blockers and run `upgrade plan --replace` explicitly.
A plan saved by a Runtime version without watermark support also requires that
replacement step, even when no local write occurred.

## Install

```sh
uvx --from qdrant-memory-mcp==0.3.6 qdrant-memory-mcp --home /path/to/profile mcp
```

The distribution resolves `hermes-plugin-qdrant-memory[mcp]==0.7.2` from PyPI.
It does not install Hermes and does not expose any Runtime maintenance command
through MCP. The managed launcher, WorkBuddy connector and DSH bundle select
their own Runtime versions and are released separately. The published launcher
`0.1.0-rc.12` still installs Runtime 0.7.1.

## VS Code Copilot verification

The candidate wheel passed desktop verification in VS Code 1.146.0 on macOS

publication.

## Watermark scope

The watermark covers writes recorded in the local Ledger of the selected
profile. It does not observe another Runtime process with a separate Ledger,
another profile or device, or direct writes from other clients to Qdrant. Stop
or isolate other writers and take the provider snapshot before an upgrade that
requires a stable destination.
