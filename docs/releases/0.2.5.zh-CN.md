# MCP 分发 0.2.5

MCP 分发 0.2.5 选择 Runtime 0.5.1。该补丁修复受保护的 Owner 恢复路径。工具
Schema、传输层与授权规则不变。

## 变更

- 选择已发布的 Runtime 0.5.1 wheel 与 `v0.5.1` 标签修订。
- 随附 launcher 0.1.0-rc.5，携带 Runtime 0.5.1 载荷与依赖锁。
- 选择 DSH bundle 0.1.4 与 Skill 0.3.4。
- 更新接入指南、版本表与 CI 固定点。

## 安装

安装包前，请检查 PyPI 是否已提供 Runtime 0.5.1。

```sh
uvx --from 'qdrant-memory-mcp==0.2.5' qdrant-memory-mcp --help
```

共享 Owner 部署需在自己的环境中安装 Runtime：

```sh
python -m venv ~/.local/share/qdrant-owner-env
~/.local/share/qdrant-owner-env/bin/pip install \
  'hermes-plugin-qdrant-memory[local,mcp,remote]==0.5.1'
```

## 升级

替换分发版本并重启 MCP 客户端。Runtime 升级保持集合标识与账本，无需迁移步骤。

## 验证与限制

- 仓库测试套件针对固定的 Runtime 运行。
- 双设备验收报告记录 Runtime 0.5.0 的实际行为，以及 0.5.1 修复的恢复缺陷。
- 托管安装使用 launcher 载荷。已预置 Runtime 0.5.0 的主机在 launcher 重新预置
  之前继续使用该环境。
