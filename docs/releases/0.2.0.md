# Qdrant Memory MCP 0.2.0

This release pins Runtime 0.4.0 and ships the shared-service preview
configurations in the source distribution.

- The package dependency is `hermes-plugin-qdrant-memory[mcp]==0.4.0`.
- The wheel remains metadata-only. It contains no runtime code.
- The sdist includes the opt-in shared preview configurations for stdio hosts,
  DSH, WorkBuddy and Codex.
- The four MCP tools and their schemas do not change.
- Private installations and managed defaults do not change.

Install:

```bash
uvx --from qdrant-memory-mcp==0.2.0 qdrant-memory-mcp --home /path/to/profile mcp
```

The shared preview needs an owner profile that runs Runtime 0.4.0. See the
[shared integration notes](../../integrations/shared/README.md).
