# MCP 分发 0.3.3

本版本将 metadata-only MCP 包对齐到已发布的 Runtime 0.6.2。MCP 0.3.2 固定依赖
Runtime 0.6.1，因此无法与当前 Runtime pin 一起正常解析。

四个 MCP 工具、schema、Qdrant schema 和持久化记忆格式均不变；本包仍是共享
Runtime 的薄适配层。
