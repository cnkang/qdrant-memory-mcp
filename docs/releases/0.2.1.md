# Qdrant Memory MCP 0.2.1

This release updates the managed launcher and closes the documentation gap for
the shared owner.

- The launcher pin moves to `@cnkang/qdrant-memory-launcher@0.1.0-rc.3`. The new
  launcher installs Runtime 0.4.0. Launcher `0.1.0-rc.2` installed Runtime 0.3.0.
- The shared-service guide no longer describes the Runtime as unreleased.
- The install examples use the published PyPI release instead of a local source
  checkout.
- The four MCP tools, the private defaults and the metadata-only wheel do not
  change.

Install:

```bash
uvx --from qdrant-memory-mcp==0.2.1 qdrant-memory-mcp --home /path/to/profile mcp
```

The WorkBuddy connector in this release packages Skill 0.3.0 and launcher
`0.1.0-rc.3`.
