# MCP distribution 0.2.8

MCP distribution 0.2.8 selects the published Runtime 0.5.4 release. Runtime
0.5.4 is a maintainability release: it keeps the behavior of 0.5.3 and moves
long functions into named helpers. This metadata-only MCP package still delegates
its implementation to the Runtime.

## Changes

- Pin `hermes-plugin-qdrant-memory[mcp]==0.5.4`.
- Update the MCP Registry metadata and the exact installation examples to 0.2.8.
- Install the test dependencies of the quality, cross-harness, DSH-next and
  WorkBuddy workflows from hash-locked files, and add a SonarCloud scan to the
  repository quality workflow for the default branch and in-repository pull
  requests.
- Move the Pi host acceptance harness to `minimatch` 11.0.1 and the WorkBuddy
  lane to `uv` 0.13.6, past their published advisories.
- Keep the four MCP tools, their schemas, stdio transport, scope rules and stored
  data unchanged. No migration or collection schema change is required.
- Keep the managed WorkBuddy launcher payload on Runtime 0.5.2: it installs the
  standalone MCP entrypoint and does not instantiate Hermes' native MemoryProvider,
  so this release needs no npm publication. The DSH bundle configuration in this
  repository now selects 0.2.8 and takes effect when that bundle is republished.

## Upgrade

Update the exact package pin and restart the MCP client so it creates a new
process. Existing profiles, model caches and memory data are reused unchanged.
