# MCP distribution 0.2.9

MCP distribution 0.2.9 selects the published Runtime 0.5.5 compatibility
release and records its immutable source revision. The Runtime release updates
FastEmbed for Pillow compatibility while preserving the existing behavior.

## Changes

- Pin `hermes-plugin-qdrant-memory[mcp]==0.5.5`.
- Update the MCP Registry metadata and exact installation examples to 0.2.9.
- Keep the four MCP tools, schemas, stdio transport, scope rules and stored data
  unchanged. No migration or collection schema change is required.
- The launcher and DSH bundle package artifacts are unchanged; this release
  does not require an npm publication.

## Upgrade

Update the exact package pin and restart the MCP client so it creates a new
process. Existing profiles, model caches and memory data are reused unchanged.
