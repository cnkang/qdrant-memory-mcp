# MCP 分发 0.3.1

MCP 分发 0.3.1 继续使用 Runtime 0.6.0 和现有四个 stdio 工具。本次更新托管
launcher 0.1.0-rc.8 的完整性固定值，使其与 npm 上实际公开的文件一致，确保
WorkBuddy 和 DSH 的发布检查验证用户真正安装的字节。MCP 协议、工具 schema、profile
及存储数据格式均未改变。

WorkBuddy connector 0.2.5 和 DSH bundle 0.1.6 固定使用经过验证的 launcher。它们的
下载附件和 npm 发布有独立的构建、验收和发布步骤。使用固定版本安装命令前，分别核验
PyPI、MCP Registry 和 npm 上的版本。

Runtime 0.6.0、Skill 0.4.0 和 Codex 插件候选版继续独立管理版本。Codex Marketplace
暂不提交。[0.3.0 升级说明](0.3.0.zh-CN.md)中关于 FastEmbed 0.9.0 到 0.9.1 管线迁移
的指导仍然适用。
