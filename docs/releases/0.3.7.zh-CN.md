# MCP 分发 0.3.7

MCP 0.3.7 是仅含元数据的 stdio 分发包，固定依赖已公开发布的 Qdrant
Memory Runtime 0.7.3，并保留四个显式作用域工具：

- `qdrant_memory_search`
- `qdrant_memory_add`
- `qdrant_memory_update`
- `qdrant_memory_delete`

此版本不改变 MCP 工具 schema、scope 行为或 Runtime 数据 schema，也不增加自动对话
采集或维护工具。

在 [PyPI](https://pypi.org/project/qdrant-memory-mcp/0.3.7/) 和
[MCP Registry](https://registry.modelcontextprotocol.io/v0.1/servers/io.github.cnkang%2Fqdrant-memory/versions/0.3.7)
均可确认精确版本 0.3.7 前，请继续使用已发布的 0.3.6。

## 安装

确认 PyPI 与 MCP Registry 均已发布 0.3.7 后，再运行：

```sh
uvx --from qdrant-memory-mcp==0.3.7 qdrant-memory-mcp --home /path/to/profile mcp
```

在此之前使用上一版：

```sh
uvx --from qdrant-memory-mcp==0.3.6 qdrant-memory-mcp --home /path/to/profile mcp
```

该分发从 PyPI 固定安装 `hermes-plugin-qdrant-memory[mcp]==0.7.3`，不安装 Hermes。
托管 launcher、WorkBuddy connector 和 DSH Bundle 使用独立版本与依赖固定。

发布 workflow 会使用公开 Runtime 验证 wheel 和 source distribution，检查 MCP Python
SDK 1.x 与 2.x 兼容性，并在发布 Registry 条目前运行 stdio 协议验收。
